# 小师妹小红书图文生产标准 v2

这是本项目的可执行标准，不是审美口号。适用于小红书 3:4 多页图文的生成、排版、导出和回归；页面数量与插图数量按文章结构在 1–8 页内增减，不固定为 N。

## 1. 一票否决项

- 每张最终页面 PNG 必须是 1080×1440。封面 KV 源图固定 9:8；正文插图固定 3:4。
- 插图源像素不得带透明边、母版分隔线、灰框或邻格残片。白色场景背景与自然留白都是内容，不把白色本身判成缺陷。
- 页面与正文默认白底；参考用户确认的本地视觉样本：封面大字橙 `#FD8502`，正文强调橙 `#E6773D`；不显示页码。
- 图文不得重叠、越出页边或底部安全区。插图靠一侧页边时，文字必须靠另一侧形成稳定阅读锚点。
- 健康与养生内容不得承诺疗效，不得把单一食材写成药方；必须保留“不替代诊疗 + 持续/加重时停用并咨询医生”的边界。
- 任一项不通过，导出必须失败并保留原稿，不得生成“看起来像成功”的发布包。

## 2. 封面标准

- 封面只承担一个记忆点：上方 1/3 放短眉题与两行以内主标题，下方 2/3 放一张 9:8 KV；KV 满宽并贴底。
- 主标题建议 6–16 个汉字；超过预算时自动降级字号，不截字。
- 封面不放正文墙、不放页码、不堆三张同权小图。
- 缩到双列信息流尺寸时，仍应先读到主题，再读到画面主体；标题区与 KV 不重叠，人物头部、手部和关键动作不能被裁掉。

## 3. 正文标准

- 一页承载 2–4 个信息单元；每个单元只讲一个动作或判断。
- 单元标题建议 2–12 个汉字；正文建议 12–60 个汉字。宁可增页，也不把整段文章塞进一页。
- 同页保留一个主信息，其他为支持或细节；连续三页不得机械复制完全相同的构图。
- 三段页默认采用左右交替：第 1/3 段文字左、图右；第 2 段图左、文字右。图和文分别对齐相反页边。
- 结尾页负责停用条件、风险边界或行动总结，不做第二张封面。

## 4. 插图与母版标准

- 母版1固定为 3×3 逻辑网格：上两行六格合并为一张连续 9:8 KV；底行从左到右是 A/B/C 三张 3:4 插图。
- 母版2起固定为 3×3 独立插图：D–L，后续按文章需要继续 M、N……；插图数量不固定为 N。
- 拆图采用“模板区域映射 → KV 输出 1080×960 / 插图输出 1080×1440 → 透明边与分隔线污染复检”。白色背景或白色留白不触发裁边。
- 网格线本体和网格线外侧的串格内容必须一起清除；只把 3–5px 分隔线涂白、却保留相邻格残片，仍按串格失败处理。
- 插图默认白色场景底；排版容器也为白色。白底图不再强制圆角矩形，也不以白色画面留白作为返工理由。
- `contain` 仅用于本来就应完整展示的贴纸/证据图；人物场景与生活插画默认 `cover`，但必须受主体焦点和 3:4 槽约束。
- 付费母版返回后，必须先登记原图与调用次数，再进入切片和视觉门；切片失败后从已付费原图恢复，禁止用重试掩盖重复计费。

## 5. 发布前现实验收

1. 机器门：源图边缘检测、页面结构评分、图文几何检查全部通过。
2. 真导出：生成 ZIP，逐页回读 1080×1440、PNG 数量、发布文案和 manifest。
3. 视觉门：桌面与窄屏逐页检查标题、页边、节奏、裁切、橙色、页码，以及自动布局后是否仍可改字、取景、移动和缩放。
4. 内容门：标题、正文、5 个标签与画面语义一致；高风险断言已删除或降级。
5. 只有以上都通过，才能称为“本地发布包可用”；不等于已经外部发布，也不等于现实传播效果已验证。

## 6. 本次事故固化

- 事故：母版分隔线被带进单图；旧 4% overscan 只能遮一部分；模型把左侧 A/B 单元画宽，固定三等分直接裁掉人物手部和关键器物；切片失败曾发生在付费原图登记之后、已付费恢复点之前。
- 根因：把生成模型画出的网格当成确定性模板；源图、容器、导出三层没有共用同一套硬门；付费调用与后处理没有分成两个可恢复事务。
- 当前合同：新母版以固定 `KV 9:8 + A/B/C` 取代旧 2×2 KV；旧自适应检测仅保留给历史付费原图重放。封面与母版共用 9:8，正文行高仍是 3:4 插图尺寸唯一权威；付费原图先登记、切片可重放；导出前检查图像比例、文字盒、页边和重叠。
- 回归资产：`src/mother-sheet-adaptive-regions.mjs`、`src/mother-sheet-artifact-cleanup.mjs`、`src/mother-sheet-tile-quality.mjs`、`src/image-run-checkpoint.mjs`、`scripts/repair-generated-run-assets.mjs`、`tests/mother-sheet-adaptive-regions.test.mjs`、`tests/mother-sheet-artifact-cleanup.test.mjs`、`tests/image-run-checkpoint.test.mjs`、`tests/sol-workbench-contract.test.mjs`。
